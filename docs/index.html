为什么不会回溯爆炸？

回溯引擎在 (a+)+$ 这类模式上会指数级重试；re-mbt 用 Brzozowski/Antimirov 导数构造惰性 DFA， 每个输入字节只推进一次状态。点击「ReDoS 压力」按钮，观察 20 万个 a 后的单次匹配耗时。

这是怎么在浏览器里跑的？

  1. playground/ 是 pkgtype(kind: "foreign_library") 的 MoonBit 包，用 #export_name 导出 re_match / re_find_len。
  2. moon build --target js --release playground 生成 playground.js（同一份源码也可构建为 wasm-gc / native）。
  3. 页面直接 import 该模块调用匹配函数；正则编译、导数、DFA 推进全部在本地完成，无服务器、无 CDN。
  4. CI 重新构建并部署到 GitHub Pages，保证页面与源码同步。

说明：页面使用 JS 目标（字符串 ABI 最直接）；仓库同时保留 wasm-gc 构建产物，四后端语义一致由 777 项测试守护。
