# 指令：性能优化 + 测试覆盖率提升

## 原始指令
general-code-harness 提供测试覆盖率和性能优化

## 澄清后的任务定义

### 执行顺序
先性能后覆盖率：先做性能优化，再补充测试覆盖。

### 阶段一：性能优化
- 方向：全面优化（算法 + 内存 + 数据结构，分轮次渐进推进）
- 方法：基于现有 benchmark 分析定位热点，针对性优化
- 约束：纯 MoonBit 实现，无 C FFI，支持 native/wasm/js 全后端
- 核心模块：cset（字符集操作）、automata（导数/状态）、compile（lazy DFA driver）、core（匹配引擎）

### 阶段二：测试覆盖率提升
- 方法：运行现有测试，分析未覆盖的 pub API 和分支，补充缺失测试
- 重点：核心模块的边界和错误路径测试
- 现状：已有 251 个测试，coverage_test.mbt 专门补充 pub API 覆盖

### 项目背景
- re-mbt：ocaml-re 到 MoonBit 的正则表达式库移植
- 匹配引擎：lazy DFA + Brzozowski/Antimirov 导数
- 32 个源文件，9 个测试文件，约 160KB 源码
- 已有 10 个 benchmark section，bench/run_bench.ps1 自动化脚本
- 当前有 250 个 warning 正在治理中（独立工作）
